# `tests/audio/fixtures/`

Local test fixtures for `svaraflow-core`.

## Why this directory is mostly empty

Binary media files must not be committed to this repository. The parent
directory (`tests/audio/`) is gitignored except for `.gitkeep`; this
directory tracks only this README and — once the first integration test
lands — one or two very small WAV files that the golden tests need to
compile against.

Target budget for a committed fixture: **under 64 KB each**, mono, 16 kHz,
PCM `s16`, under one second. Anything larger belongs on the developer's
disk, not in Git.

## What to drop here

For the silence-detector integration tests you will want:

| File | Contents | Purpose |
| --- | --- | --- |
| `silence_then_tone.wav` | 1 s of digital silence followed by 1 s of a 1 kHz sine at −12 dBFS | Asserts that the detector marks the first second as silence and the second as sound. |
| `tone_then_silence.wav` | The reverse | Asserts that the trailing edge snaps to the lowest-energy frame within 100 ms. |
| `short_blips.wav` | Five 100 ms 1 kHz blips separated by 50 ms of silence | Asserts that `KEEP_TALKS = 0.25` drops the blips and that `REMOVE_SILENCES = 0.50` fills the gaps. |

Until they are committed, every integration test under `svaraflow-core/tests/`
must `#[ignore]` itself and start with a `if !path.exists() { return }` guard
so that CI on a fresh clone stays green.

## How to generate them

Any of these work. Pick one and document it in the test file that uses the
fixture.

```
powershell
# ffmpeg: 1 s silence + 1 s 1 kHz tone at -12 dBFS
ffmpeg -y `
  -f lavfi -i "anullsrc=r=16000:cl=mono:d=1" `
  -f lavfi -i "sine=frequency=1000:sample_rate=16000:duration=1" `
  -filter_complex "[0:a][1:a]concat=n=2:v=0:a=1,volume=-12dB" `
  -ac 1 -ar 16000 -c:a pcm_s16le silence_then_tone.wav
```
```
# Python (no dependencies): 1 s silence + 1 s 1 kHz sine

import math, struct, wave
with wave.open("silence_then_tone.wav", "wb") as w:
    w.setnchannels(1); w.setsampwidth(2); w.setframerate(16000)
    frames = [0] * 16000
    amp = int(0.25 * 32767)  # -12 dBFS
    frames += [int(amp * math.sin(2 * math.pi * 1000 * i / 16000)) for i in range(16000)]
    w.writeframes(b"".join(struct.pack("<h", s) for s in frames))
```

## What not to put here
- Real interview audio, screen recordings, or anything with a person in it.

- Files over 64 KB.

- Any file whose licence you do not control. Fixtures must be generated by
the script in this README, or be in the public domain.

- `timeline.json` files — those are text and belong next to the test that
uses them, in `svaraflow-core/tests/`.
